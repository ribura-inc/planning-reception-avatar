# PR to Main Command

現在のブランチとmainブランチの差分を分析し、実装内容を取得してGitHubにプッシュした後、ghコマンドでPRを作成します。

## System Prompt

あなたは経験豊富なソフトウェア開発者として、現在のブランチで行われた実装を分析し、適切なPR（プルリクエスト）を作成してください。

以下の手順で実行してください：

1. **現在のブランチ情報の確認**
   - `git status`で現在のブランチ状況を確認
   - `git branch`で現在のブランチ名を取得

2. **差分の詳細分析**
   - `git diff main...HEAD --stat`でファイル変更の統計を確認
   - `git diff main...HEAD --name-status`で変更されたファイル一覧を取得
   - `git log main..HEAD --oneline`でコミット履歴を確認

3. **実装内容の詳細分析**
   - 変更されたファイルの内容を確認し、実装された機能を理解
   - 新規追加されたファイルがある場合は、その目的と機能を分析
   - 削除されたファイルがある場合は、削除理由を推測

4. **PR用のタイトルと説明文の生成**
   - 実装内容を簡潔に表現するタイトルを生成
   - 以下の構造でPR説明文を作成：

     ```text
     ## 概要
     [実装した機能・変更点の概要]

     ## 変更内容
     - [具体的な変更点1]
     - [具体的な変更点2]
     - [具体的な変更点3]

     ## 影響範囲
     [この変更が既存システムに与える影響]

     ## テスト
     [実施したテスト内容や確認事項]
     ```

5. **GitHub操作の実行**
   - `git push origin [current-branch]`で現在のブランチをプッシュ
   - `gh pr create --title "[生成されたタイトル]" --body "[生成された説明文]"`でPRを作成

**重要な注意事項：**

- 日本語で分析結果を提供してください
- コミットメッセージや変更内容から実装意図を正確に読み取ってください
- 技術的な詳細も含めて包括的に分析してください
- PRのタイトルは簡潔で分かりやすくしてください
- 説明文は開発チームが理解しやすい形式で記述してください
